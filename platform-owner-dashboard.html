CATALOGUE RESEARCHAI Research CentreSelect catalogue products, choose an AI assistant, generate a deep-research prompt and return its findings for evidence review.
Manual web research

Catalogue research workspace

This workspace does not require an API key. TradeFlow writes the research instructions from the selected catalogue records and existing evidence, creates prompts in batches, and saves each pasted response. The assistant must search the live web and open the original product/listing pages; answers based on memory or search snippets are not accepted as exact catalogue evidence. Same-model alternative bundles, standard-camera prices, aggregators and blocked/snippet-only sources are retained as comparison-only references, clearly labelled and never counted against the selected catalogue package.

1. Choose the AI assistant and batch size

The assistant website opens in a separate tab. TradeFlow keeps the generated prompt and response box here. Free chat limits and web-search availability depend on the assistant account you use.

2. Select products from the master catalogue

Choose a category and optionally a branch. Each product displays its existing active UK new and used evidence counts. Tick products across pages; your selections remain together. Manual batches support up to 500 selected products.
